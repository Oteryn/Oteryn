## Execution objective

For each repository, determine the instruction surface an ordinary agent can actually encounter and classify active/reachable guidance as:

`KEEP_ALWAYS`, `ROUTE`, `TASK_ONLY`, `DETERMINISTIC`, `ARCHIVE_INERT`, `REMOVE_DUPLICATE`, or `UNKNOWN_NEEDS_EVAL`.

Use this decision test:

> Would omitting this instruction from an ordinary task materially increase the risk of an incorrect result or unauthorized effect before a routed source or deterministic control can handle it?

If not, it does not belong in `ALWAYS`.

Prefer the smallest coherent change that improves the effective context/control surface. Deletion or routing is preferable to rewriting when no unique semantic value remains. Do not change a repository merely to produce a diff; record `NO_CHANGE_REQUIRED` when its active surface is already proportionate.

Preserve unique domain and architecture knowledge. Do not weaken deterministic enforcement. Rulesets, required checks, Merge Queue, validators, schemas and permissions should carry deterministic controls where they already do so; keep only the agent-facing prose needed to choose a safe action before those controls are reached.

Historical material may remain in Git, but it must not masquerade as current dispatch authority or become ordinary context merely because a broad search finds it.

A blocked operation does not block safe independent work elsewhere. Report a blocker only when no authorized route can advance the affected required result. Do not create no-op commits, repeated checkpoints or unchanged heavy validation as progress.
