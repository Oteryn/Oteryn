# Oteryn

Oteryn is the ecosystem **META / coordination plane** for the Oteryn project.

This repository owns cross-repository topology authority, ecosystem-level architecture decisions, compatibility and release coordination metadata, and shared governance contracts. Product runtime implementation remains in the product repositories.

## Ecosystem repositories

- `Oteryn/Oteryn` — META / coordination
- `Oteryn/Oteryn-Game` — Game runtime and client
- `Oteryn/Oteryn-Platform` — Platform and infrastructure
- `Oteryn/Oteryn-Atlas` — Atlas

## Agent tooling

Agents can consult `docs/agents/AVAILABLE_TOOLS.md` for the coordination and development tools available to them in supported execution environments.

## Source of truth

Live GitHub state and provider-owned repository content remain authoritative for technical facts. Coordination metadata must stay aligned with those sources.
